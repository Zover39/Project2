# Astana Travel

Веб-приложение для поиска и сравнения отелей и планирования поездок. Каталог включает направления в ОАЭ, Турции, Таиланде, Египте, на Мальдивах, во Вьетнаме и на Бали.

## Запуск локально

Требуется Node.js 18.17 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для production-сборки и локального запуска используйте:

```bash
npm run build
npm start
```

## Страницы

- `/` — каталог и рабочее пространство приложения
- `/catalog` — каталог отелей
- `/favorites` — избранное
- `/trip-finder` — подбор поездки
- `/compare` — сравнение отелей
- `/recent` — недавно просмотренные отели
- `/tinder` — подбор отелей в формате карточек
- `/ai-assistant` — помощник по поездкам
- `/account` — профиль
- `/admin/dashboard`, `/admin/bookings`, `/admin/hotels`, `/admin/customers`, `/admin/reviews` — разделы администрирования

## Данные

Каталог и начальные данные находятся в `src/data/appData.js`. Настройки каталога собраны в `src/data/config.js`; общие форматирование и расчёты — в `src/utils/`.

Избранное, бронирования, история просмотров, сравнение и настройки интерфейса сохраняются в `localStorage` браузера. Приложение использует демонстрационные данные и не требует файла `.env` для локального запуска.

На странице избранного можно скачать список отелей и заметки в CSV для дальнейшего планирования или открытия в табличном редакторе.
