# Техническое задание: сайт турагентства «Горизонт» (Астана)

## 1. Цель
Многостраничный сайт-витрина турагентства: каталог туров, страницы туров с бронированием, информация о компании и вопросы клиентов. Основная метрика: заявки (бронирование и консультация).

## 2. Целевая аудитория
Жители Астаны и Казахстана 25–55 лет, ищут тур с перелётом, отелем и визовой поддержкой. Чаще заходят с телефона.

## 3. Стек
- Next.js 15 (App Router), React 19, TypeScript, чистый CSS
- Шрифты через next/font: Unbounded (заголовки), Onest (текст)
- Редактор VS Code, деплой Vercel. Бэкенда на этом этапе нет.

## 4. Страницы
| Адрес | Содержимое |
|---|---|
| / | Первый экран с табло вылетов из Астаны, горящие туры, этапы работы, цифры, форма консультации |
| /tours | Каталог: поиск, вкладки по типу отдыха, ползунок бюджета, сортировка |
| /tours/[id] | Страница тура: описание, что входит, остаток мест, форма бронирования с расчётом цены на группу |
| /about | О компании, цифры, отзывы |
| /faq | Частые вопросы, список документов для поездки |
| /contacts | Контакты и форма заявки |

## 5. Дизайн
Палитра: песок #f4efe6, морской графит #0e2a3a, коралловый #ff7a59. Фирменный элемент: табло вылетов в стиле аэропорта. Адаптивность от 360 px, видимый фокус, контраст не ниже AA, отключение анимации при prefers-reduced-motion.

## 6. Функциональные требования
- Фильтрация каталога на клиенте (поиск, тип, бюджет, сортировка)
- Расчёт стоимости по числу человек в форме бронирования
- Проверка телефона (не менее 10 цифр), сообщения об ошибке и успехе
- Данные туров, отзывов и вопросов в lib/data.ts
- SEO: title и description на каждой странице, lang="ru"

## 7. Этапы
| Этап | Содержание | Статус |
|---|---|---|
| 1 | Фронтенд сайта (этот проект) | Готов |
| 2 | Реальные тексты, фото туров, цены и даты | Дальше |
| 3 | Бэкенд: приём заявок, база туров, админка | Дальше |
| 4 | Оплата онлайн, аналитика, согласие на обработку данных | Дальше |
| 5 | Домен, деплой, проверка Lighthouse | Дальше |

## 8. Приёмка
Проект запускается командой npm run dev без ошибок, все страницы открываются, фильтры и формы работают, вёрстка корректна на телефоне.
